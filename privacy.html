개인정보처리방침

상태: 게시 전 초안 · 시행일: 실제 게시 시 확정

1. 운영 목적과 대상

본 프로그램은 운영자 자신의 주식 연구 기록을 보관·확인하기 위한 개인용 프로그램입니다. 공개 회원가입이나 다른 사람의 Google 계정 자료 수집을 목적으로 하지 않습니다.

2. 처리하는 정보

프로그램은 종목코드·수급·가격의 API 원본 응답, 선정 규칙과 결과, 사후 평가 및 저장 확인 기록을 처리합니다. 해당 Drive 파일의 이름·식별번호·생성 시각·버전·내용 일치 확인값 등도 처리합니다.

Google 접근을 위해 OAuth 인증정보를 사용합니다. 접속 토큰과 갱신 토큰을 담은 Google 인증 자료는 운영 PC에서 Windows 사용자 기반 암호화로 보관합니다. OAuth 설정 파일은 PC의 별도 비공개 폴더에 보관합니다.

실제 가동 시 기존 키움 토큰을 읽어 시장 자료 조회에 사용합니다. 본 프로그램은 키움 토큰을 발급·갱신·삭제하지 않습니다.

계정 이름·이메일·프로필 조회를 위한 추가 권한은 요청하지 않습니다.

3. 이용 목적과 접근 범위

정보는 연구 기록 저장, 최초 저장 버전 보관, 저장 내용 확인, 사전 선정과 사후 평가의 연결에 사용합니다.

Google Drive 접근 범위는 drive.file 권한으로 허용되는 파일에 한정합니다. 연구 결과가 공개 안내 페이지에 게시되도록 설계하지 않았습니다.

4. 저장과 외부 서비스 이용

연구 기록은 운영 PC와 운영자가 지정한 Google Drive 폴더에 저장합니다. 특별 개장일과 선정 마감 경과에 따른 보류 기록은 PC에만 저장하며, 업로드 실패 시에도 로컬 기록만 남을 수 있습니다.

Windows 사용자 기반 암호화는 Google 인증 자료에 적용됩니다. 로컬 연구 기록은 프로그램에서 별도로 암호화하지 않습니다.

프로그램은 인증정보를 연구 파일에 포함하거나 화면·일반 로그에 출력하지 않도록 설계되었습니다.

현재 프로그램에는 ChatGPT로 파일을 자동 전달하거나 분석을 실행하는 기능이 없습니다. 운영자가 별도로 연결한 Drive를 통해 ChatGPT에 선택한 연구 파일의 분석을 요청할 수 있습니다. 이 경우 해당 파일의 내용이 ChatGPT에서 처리되며, 해당 서비스의 설정과 정책도 적용됩니다.

Google 사용자 데이터를 판매하거나 광고 목적으로 이용하지 않습니다. Google API로 받은 정보의 이용에는 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건을 준수합니다.

5. 보관과 삭제

연구 기록은 운영자가 연구·검증 목적으로 보관하는 동안 유지하며 자동 삭제 기간은 설정하지 않습니다.

현재 프로그램에는 저장 자료를 삭제하는 기능이 없습니다. 운영자는 PC와 Google Drive에서 파일을 직접 삭제할 수 있습니다. Drive에서 보존하도록 지정한 최초 버전도 삭제 불가능한 기록을 의미하지 않습니다.

다른 서비스에 별도로 전달한 자료는 해당 서비스에서 별도로 관리·삭제해야 합니다.

6. 접근 철회

현재 프로그램에는 Google 접근 권한을 철회하는 기능이 없습니다. 운영자는 Google 계정의 연결 관리 화면에서 직접 접근 권한을 철회할 수 있습니다.

접근 철회만으로 이미 저장된 연구 파일이 자동 삭제되지는 않습니다.

7. 정책 변경과 문의

처리 목적이나 외부 전달 범위가 달라지면 적용 전에 이 방침을 수정하고 시행일을 표시합니다.
